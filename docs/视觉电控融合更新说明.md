## 一、更新背景

视觉系统 (Radxa Cubie A7Z) 通过 UART 发送 `$type,cx,cy,area,dir*CS\n` 给 STM32。此前存在两个问题：

1. **远距离友方误后退**: 视觉检测到很远的己方能量块也发 `F`，STM32 收到 `F` 就无条件后退，浪费比赛时间
2. **视觉数据未被充分利用**: `area`（面积/距离）和 `dir`（方向）已经在传输，但 STM32 只用了 `type` 字段，`area` 和 `dir` 被浪费了

本次更新在**不破坏现有逻辑**的前提下，新增 3 项视觉×电控融合能力。

## 三、详细说明

### P1: 友方距离过滤 — 远距离己方能量块不后退

**问题**: 远处的己方能量块被视觉检测到后发 `F`，STM32 无条件执行 F/B 回避（后退+掉头），导致机器人在远离己方块时也会莫名后退。

**解决方案**: 利用已有的 `vision_target.area` 字段，`area` 是面积也是距离的代理指标——面积越大目标越近。只有 `area >= 5000` 的近距离友方才触发后退。

**新增宏** (`robot_fight.h`):
```c
#define FIGHT_FRIEND_MIN_AREA 5000  // 友方最小面积: area < 此值时忽略 F
```

**改动位置** (`robot_fight.c` 约第 399 行):
```c
// 改前: F 和 B 都无条件触发后退
if((vision_type == 'F' || vision_type == 'B') && ...)

// 改后: F 需要检查 area，B 仍无条件触发
if(vision_type == 'B' ||
   (vision_type == 'F' && vision_target.area >= FIGHT_FRIEND_MIN_AREA))
```

**调参建议**: 如果 5000 太小（近距离才后退），可以适当增大；如果 5000 太大（还是会远距离后退），可以减小。`area` 参考值：
- 近距离（面前）: area > 12000
- 中距离: area 5000~12000
- 远距离: area < 3000

### P2: 视觉方向辅助 IR — 补充 IR 盲区

**问题**: 红外传感器有盲区——IR 都没触发 (`DIR_NONE`) 但视觉已经看到了目标。此时机器人判定"无目标"开始丢失计时，白白浪费追踪机会。

**解决方案**: 当 `Fight_GetEnemyDir() == DIR_NONE` 且视觉有有效目标 (E/N 类型) 时，用视觉的 `dir` 字段补充方向。

**新增宏** (`robot_fight.h`):
```c
#define FIGHT_VISION_DIR_LEFT_THRESH  (-30)  // dir < -30 → 前左
#define FIGHT_VISION_DIR_RIGHT_THRESH  (30)  // dir > +30 → 前右
```

**改动位置** (`robot_fight.c` 约第 342 行，在 `Fight_GetEnemyDir()` 之后):
```c
raw_dir = Fight_GetEnemyDir();

// P2: IR 盲区时用视觉方向补充
if(raw_dir == DIR_NONE && !Vision_IsTimeout() && vision_target.valid &&
   vision_target.type != 'F' && vision_target.type != 'B' && vision_target.type != 'X')
{
    int8_t vdir = vision_target.dir;
    if(vdir < -30) raw_dir = DIR_FRONT_LEFT;
    else if(vdir > 30) raw_dir = DIR_FRONT_RIGHT;
    else raw_dir = DIR_FRONT;
}
```

**注意**:
- 只在 IR 全无触发时才用视觉补充，**IR 有信号时视觉不覆盖**
- 排除 F/B/X 类型，只对 E（敌方）和 N（中立）补充方向
- `dir` 范围 [-100, +100]，阈值 ±30 对应画面中心 ±30% 偏移

---

### P3: 视觉引导攻击 — 漫游阶段用视觉触发进攻

**问题**: 当前 `ROBOT_ROAMING → ROBOT_ATTACK` 的转换**完全依赖 IR 传感器**。如果视觉已经看到近处的敌方/中立能量块，但 IR 还没碰到（目标在 IR 盲区），机器人不会进入攻击。

**解决方案**: 在 `robot_control.c` 的 `ROBOT_ROAMING` 分支中，IR 无触发时检查视觉数据——如果视觉看到 E/N 类型且 `area > 3000`（足够近），主动进入 `ROBOT_ATTACK`。

**新增宏** (`robot_fight.h`):
```c
#define FIGHT_VISION_ATTACK_MIN_AREA 3000  // area > 此值才从漫游进攻击
```

**改动位置** (`robot_control.c` 约第 59 行):
```c
enemy_dir = Fight_GetEnemyDir();
if (enemy_dir != DIR_NONE)
{
    Fight_InitWithDir(enemy_dir);
    robot_state = ROBOT_ATTACK;
}
// P3: IR 无触发但视觉看到目标
else if (!Vision_IsTimeout() && vision_target.valid &&
         (vision_target.type == 'E' || vision_target.type == 'N') &&
         vision_target.area > FIGHT_VISION_ATTACK_MIN_AREA)
{
    EnemyDir vdir;
    if (vision_target.dir < -30)      vdir = DIR_FRONT_LEFT;
    else if (vision_target.dir > 30)  vdir = DIR_FRONT_RIGHT;
    else                               vdir = DIR_FRONT;
    Fight_InitWithDir(vdir);
    robot_state = ROBOT_ATTACK;
}
```

**注意**:
- IR 优先级仍然最高——有 IR 信号时视觉不参与
- `area > 3000` 避免追太远的目标（省时间）
- 进入攻击时用视觉方向初始化，让 `Fight_InitWithDir` 一开始就有正确方向

## 四、视觉数据说明

### UART 协议（未改动）

```
$type,cx,cy,area,dir*CS\n

type:  E=敌方  N=中立  F=友方  X=无目标  B=炸弹  G=冲台
cx,cy: 目标中心像素 [0-640, 0-480]
area:  目标面积（像素），越大越近
dir:   方向 [-100,+100]，负=左 正=右
CS:    XOR 校验和
```

### 关键字段含义

| 字段 | 用途 | 参考值 |
|------|------|--------|
| `area` | 距离代理 | 远(<3000) / 中(3000~12000) / 近(>12000) |
| `dir` | 水平方向 | 正前(±30) / 偏左(<-30) / 偏右(>+30) |
| `type` | 目标分类 | E=推 / N=推 / F=避 / B=避 / X=忽略 |

### 视觉侧的双保险

视觉侧也加了同样的 `area >= 5000` 过滤——远距离友方直接发 `X` 而非 `F`。这意味着：
- **视觉不发**: 远距离友方 → 发 `X`（第一层过滤）
- **STM32 不理**: 即使视觉误发了 `F`，`area < 5000` 也不触发后退（第二层保险）

## 五、调参指南

所有阈值都在 `robot_fight.h` 中定义为宏，方便调整：

| 宏 | 默认值 | 影响 | 调大 | 调小 |
|-----|--------|------|------|------|
| `FIGHT_FRIEND_MIN_AREA` | 5000 | F 后退灵敏度 | 更近才后退 | 更远就后退 |
| `FIGHT_VISION_DIR_LEFT_THRESH` | -30 | 视觉方向死区 | 死区更大，偏差容忍更高 | 死区更小，方向更敏感 |
| `FIGHT_VISION_DIR_RIGHT_THRESH` | 30 | 同上 | 同上 | 同上 |
| `FIGHT_VISION_ATTACK_MIN_AREA` | 3000 | 视觉触发攻击距离 | 更近才攻击 | 更远就攻击 |

## 七、风险评估

| 风险 | 概率 | 后果 | 缓解 |
|------|------|------|------|
| P2 视觉方向不准导致追错方向 | 低 | 追偏一次 | IR 恢复后立即修正；视觉只补充前扇区 |
| P3 视觉误触发攻击 | 低 | 多一次进攻循环 | `area > 3000` 门槛 + 视觉消抖 |
| P1 阈值不合适 | 中 | 近距离才后退/远距离还后退 | `FIGHT_FRIEND_MIN_AREA` 调参 |

**安全底线不变**: 灰度掉台检测、IR 边缘检测、视觉类型消抖（连续 2 帧）——这些安全机制完全没有改动。
